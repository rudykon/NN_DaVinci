# NN_DaVinci 0.4.1 — Publication Quality Hotfix

0.4.1 fixes the paper-production failure where valid files were generated by shrinking a complete
operation graph into half a page. It does not add frameworks, analyzers, cloud features or release
infrastructure.

## Paper-ready examples

The ResNet50, Vision Transformer and multiscale U-Net examples now pair a stage-level semantic
overview with one provenance-backed representative detail. ResNet stages are derived from numbered
framework module paths and contiguous stem/head topology. The details show a bottleneck `×16`, a
Transformer block `×3` and an encoder unit `×3`; their project data records semantic confidence,
reasons, module prefix and source node/edge IDs. Unknown content remains visibly unknown.

Paper View groups only high-confidence structurally equivalent regions. Labels use real local-font
glyph advances, deterministic wrapping and concise display aliases while retaining original labels
and operator types in provenance. Composer calculates the physical panel budget first, adapts panel
widths, expands nodes, balances row gaps and refuses `paper_ready` when 7 pt or whitespace gates
cannot be met. Glyphs are never horizontally compressed.

## Physical output and release blocker

The three landed SVG and PDF pages are truly 178 × 118 mm. Their PDF proofs are independently
rendered by `pdftoppm` at 300 DPI to 2103 × 1394 PNGs; each example includes `before.png`,
`after.png` and `before-after.png`. SVG, PDF, TikZ and editable PPTX remain the primary deliverables.

`product/publication-quality/acceptance.json` is now mandatory. It consumes an independent Chrome
measurement of the landed SVGs plus `pdfinfo` and reopened PNGs. All three figures must have
minimum font ≥ 7 pt, exact 1.0 horizontal/transform text scale, and zero overflow, overlap,
edge-node collision, clipping, unexplained crossing, title/legend/group-label conflict, marker
collision and endpoint error. It also checks physical page size and balanced panel occupancy.

The inherited 143 Python tests, ten legacy Chrome scenarios, semantic workflow and 0.4 product
workflow remain mandatory. A successful fresh run is written to `artifacts/v0.4.1/<run_id>`.

## Human decisions that remain

Researchers still decide scientific terminology, which evidenced structure deserves emphasis,
venue-specific caption wording and whether the visual argument matches the experiments. Automatic
layout faults are not classified as human judgment.
