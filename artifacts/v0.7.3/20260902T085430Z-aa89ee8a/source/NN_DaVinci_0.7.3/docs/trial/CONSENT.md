# Consent for Local Researcher Trial Recording

## What you are being asked to do

Use NN_DaVinci to import or select a model, inspect its semantics, compose a paper figure, recover a
saved project and export editable files. The expected task takes up to 30 minutes.

## Data recorded by Trial Mode

If and only if you tick the consent box and enable Trial Mode, the tool stores a local JSON event log.
It contains event types, elapsed times, size/count fields, export formats, broad error categories and
recovery actions. A strict schema rejects extra fields.

Trial Mode does **not** store or upload model data, weights, input samples, filenames, filesystem paths,
node/edge identifiers, label contents, search terms, comments, demographic data or identity. The Web
server has no upload destination for trial events. Qualitative comments are not part of Trial Mode and
require the facilitator to ask separately before recording them.

## Choice, risks and withdrawal

Participation is voluntary. The main risk is accidental disclosure if someone else can read your local
account; trial files therefore use restrictive local permissions. Trusted Python or pickle input may
execute code, independently of Trial Mode, and should only be approved for a source you trust.

You may decline, stop, inspect/download the JSON, revoke consent or request deletion at any time without
penalty. Revocation stops future recording and closes the active session; it does not silently erase a
file you may wish to inspect. Ask the facilitator to delete it if desired.

## Explicit agreement

By personally checking the consent box in the Trial Mode dialog, you confirm that you have read this
document, understand the local-only fields and voluntarily agree to local event recording for this
task. Opening the application or accepting a study invitation is not consent.
