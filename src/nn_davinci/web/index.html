推荐流程

  1. 从 Start Center 选择真实模型或导入文件。
  2. 在 Stage/Block/Operation 间钻取并审查 provenance。
  3. 生成论文图并比较最多三个候选。
  4. 进入 Composer 组合 Panel，完成少量拖动和路由。
  5. 保存项目并导出矢量产物。

Python factory 与 pickle 默认不执行；unknown 语义不会被猜测。
